📌 Petunjuk Penggunaan

  • Klik Mode User untuk input data harian, lalu tekan Simpan Draft atau Simpan & Selesai (Final).

  • Data tersimpan di browser (LocalStorage) — jangan membersihkan data browser agar riwayat tetap ada.
