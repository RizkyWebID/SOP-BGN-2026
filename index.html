📌 Petunjuk Penggunaan

  • Klik Mode User untuk input data harian, kemudian tekan Simpan Draft atau Simpan & Selesai (Final).
  • Setelah final, buka Mode Admin untuk memverifikasi dan mencetak dokumen.
  • Data tersimpan otomatis di browser (LocalStorage) — jangan membersihkan data browser agar riwayat tetap ada.
